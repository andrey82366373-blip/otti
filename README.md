# Otti — английский с ИИ-репетитором

Otti — веб-приложение для изучения английского: короткие уроки по маршруту от A1 до B2,
словарь, работа над ошибками и ИИ-репетитор — выдра Отти.

Готовы **все 13 этапов MVP**: уроки A1 с проверкой ответов и XP, серия дней и достижения, словарь
с повторением карточками, работа над ошибками, ИИ-репетитор Отти (GigaChat, запасные OpenRouter
и YandexGPT) с лимитами и выключателем, голосовой ввод, установка на телефон (PWA), проверка
доступности, защита сайта, смена пароля и удаление аккаунта.
Страница проверки: `/status`. Чек-лист запуска и управления сайтом — в файле **LAUNCH.md**.

## Что нужно на компьютере

- **Node.js** версии LTS (20.9 или новее) — https://nodejs.org
- **VS Code** — https://code.visualstudio.com
- **Git** — https://git-scm.com

## Как запустить

1. Откройте папку проекта в VS Code: **File → Open Folder…** → папка `otti`.
2. Откройте терминал: **Terminal → New Terminal**.
3. Один раз установите библиотеки (1–3 минуты):

   ```
   npm install
   ```

4. Запустите сайт:

   ```
   npm run dev
   ```

5. Откройте в браузере адрес **http://localhost:3000**.
6. Чтобы остановить сайт, нажмите в терминале **Ctrl + C**.

## Полезные команды

| Команда         | Что делает                                      |

| `npm install`   | Устанавливает библиотеки (после скачивания)     |

## Учебный курс

- Уроки лежат в файлах `src/content/course/`, а в базе хранится только прогресс по ним.
- Ответы проверяются сразу в браузере, а при завершении урока сервер проверяет их ещё раз
  и только потом начисляет XP (правила — в `src/lib/xp.ts`).
- Задания с ошибкой повторяются в конце урока (до 3 попыток), а сами ошибки сохраняются
  для раздела «Работа над ошибками».
- У каждого урока и задания есть постоянный `id` (например, `a1-intro-l1-ex3`). Не меняйте его
  после публикации — к нему привязан прогресс учеников.

## Серия дней и достижения

- Серия растёт, когда за день набрана дневная цель по XP, и обнуляется, если день пропущен
  (день считается по московскому времени).
- 11 достижений описаны в `src/lib/achievements.ts` и выдаются автоматически.

## Словарь

- Новые слова урока попадают в словарь сами, когда урок пройден.
- У слова три статуса: **новое → учу → выучено**. Выученным слово становится после трёх
  «Помню» подряд, а «Не помню» возвращает его в повторение.
- Повторения идут с растущими интервалами: 1, 3, 7, 14 и 30 дней (правила — в `src/lib/words.ts`).
- За «Помню», когда у слова подошёл срок, начисляется 1 XP. Свободная тренировка XP не даёт.
- Озвучка слов работает через встроенный синтезатор речи браузера — бесплатно и без ключей.

## Работа над ошибками

- Задание, в котором ученик ошибся в уроке, попадает в раздел «Ошибки» — с его ответом,
  правильным ответом, типом ошибки и темой урока.
- Ошибка исправлена, когда задание решено правильно: в тренировке ошибок или с первой попытки
  при повторном прохождении урока. За исправление в тренировке +1 XP.
- Если ответить неверно, задание остаётся в списке и ещё раз показывается в конце тренировки.
- Правила — в `src/lib/mistakes.ts`, работа с базой — в `src/lib/mistake-store.ts`.

## База данных

- **В интернете** сайт использует облачную базу **Neon**. Она подключается на Vercel во вкладке
  **Storage**, а адрес базы (`DATABASE_URL`) Vercel добавляет в настройки сам.
- **На компьютере** используется локальная база в папке `.data`. Ничего настраивать не нужно:
  `npm run dev` сам создаёт таблицы перед запуском.
- Таблицы описаны в `src/db/schema.ts`. При каждой публикации на Vercel недостающие таблицы
  создаются автоматически.

## Вход и регистрация

- Ученик регистрируется по имени, e-mail и паролю. Пароль хранится только в виде хеша.
- Экраны приложения открываются только после входа, иначе — переход на `/sign-in`.
- В интернете включена защита от подбора пароля: не больше 10 попыток входа в минуту с одного адреса.
- На Vercel обязательно задайте переменную `BETTER_AUTH_SECRET` (как её получить — в `.env.example`).

## ИИ-репетитор

- Все запросы к ИИ идут только с сервера через `src/lib/ai/index.ts`. Ключи API в браузер не попадают.
- Провайдеры: **GigaChat** (основной, бесплатный пакет для физлиц), **OpenRouter** (запасной,
  бесплатные модели), **YandexGPT** (платный запасной), **mock** — тестовый режим без ключей.
  Какой использовать, задаёт переменная `AI_PROVIDER`, запасной — `AI_FALLBACK_PROVIDER`.
- Если основной провайдер не ответил, запрос уходит запасному.
- Лимиты: сообщений на ученика в минуту и в день и на весь сайт в день; длина сообщения и ответа.
  Значения — в `.env.example`.
- Выключить ИИ на всём сайте: переменная `AI_ENABLED=false` (на Vercel — затем Redeploy).
- Проверить подключение: страница `/status` → «Проверить связь с Отти».
- Для GigaChat нужен сертификат Минцифры — он уже встроен в проект
  (`src/lib/ai/russian-ca.ts`) и используется только для запросов к GigaChat.

## Чат с Отти

- Темы разговоров — в `src/lib/tutor/scenarios.ts`. Первая реплика Отти готовая и не тратит запрос к ИИ.
- На каждое сообщение ИИ возвращает реплику, перевод, исправление (если есть ошибка) и 0–2 новых слова.
  Исправление показывается карточкой «Твой ответ / Правильно / Почему / Естественнее».
- Отти учитывает уровень, цель, слова из словаря, недавние ошибки и советы прошлых занятий.
- «Завершить» — итоги занятия и домашнее задание (+5 XP). Цифры в итогах считает сайт, а не ИИ.
- За сообщение на английском +1 XP (до 10 сообщений в день). Задача дня — 3 сообщения.
- Язык объяснений (по-русски или по-английски) выбирается в профиле.
- Ответы «своими словами» в уроках, которые не совпали с образцами, проверяет ИИ. Сервер засчитывает
  такой ответ, только если сохранил решение ИИ (таблица `ai_answer_checks`).

## Приложение на телефоне (PWA)

- Сайт можно установить как приложение: на Android — меню браузера → «Установить приложение»,
  на iPhone — Safari → «Поделиться» → «На экран „Домой“». Подсказка есть в профиле.
- Service worker (`public/sw.js`) не сохраняет страницы и данные — он только показывает страницу
  «Нет подключения», если пропал интернет. Поэтому устаревших версий сайта не бывает.
  При разработке (`npm run dev`) он не подключается.

## Голосовой ввод

- В чате с Отти есть кнопка микрофона: браузер распознаёт английскую речь и вставляет текст в поле.
- Работает в Chrome, Edge, Яндекс Браузере и Safari; в Firefox кнопки нет. Ключи и настройки не нужны.
- Распознаванием занимается сам браузер (например, Chrome отправляет звук в сервис Google).

## Доступность

- Все экраны проверены автоматически (axe-core) в светлой и тёмной теме на ширине 320 и 1280 px:
  контраст текста, заголовки, подписи кнопок, области страницы. Горизонтальной прокрутки нет.
- Есть ссылка «Перейти к содержимому» для клавиатуры, фокус виден, анимации отключаются
  системной настройкой «Уменьшить движение».

## Безопасность

- Ключи API читаются только на сервере; в браузер не попадают.
- Каждое серверное действие проверяет вход и то, что ученик работает только со своими данными.
- Ответы в уроках, повторении слов и работе над ошибками перепроверяет сервер; опыт нельзя
  «накрутить»: за повтор урока — раз в день, за слово — не чаще раза в 12 часов, за исправления
  ошибок и сообщения Отти — дневные пределы.
- Защитные заголовки (CSP, запрет встраивания в чужие сайты и др.) — в `next.config.ts`.
- Регистраций — не больше 5 в час с одного адреса; новым аккаунтам в первые сутки доступно
  меньше сообщений Отти (`AI_NEW_USER_DAILY_LIMIT`).
- Подробности на `/status` видны только владельцу (`ADMIN_EMAILS`).
- Ученик может сменить пароль и удалить аккаунт в профиле; удаление стирает все его данные.

## Секретные настройки

Секреты (ключи API, пароль базы данных) хранятся только в файле `.env.local` на вашем
компьютере и в настройках проекта на Vercel. Файл `.env.local` никогда не отправляется
на GitHub. Список нужных настроек — в `.env.example`.

## Частые проблемы

- **«npm не является внутренней или внешней командой»** — Node.js не установлен
  или компьютер не перезагружен после установки.
- **«выполнение сценариев отключено в этой системе»** — выполните в терминале
  `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`, затем введите `Y`.
- **Страница `/status` показывает «Не подключена» на Vercel** — подключите Neon во вкладке
  Storage проекта и сделайте Redeploy.
- **`/status` пишет «Вход и регистрация: Не настроены»** — на Vercel нет переменной
  `BETTER_AUTH_SECRET`. Добавьте её в Settings → Environment Variables и сделайте Redeploy.
- **`/status` пишет «ИИ-репетитор: Тестовый режим»** — не задан ключ GigaChat. Добавьте
  `GIGACHAT_AUTH_KEY` в файл `.env.local` (на Vercel — в Environment Variables) и перезапустите сайт.
- **«GigaChat: ключ не подошёл»** — ключ скопирован не целиком или с лишними символами. Получите
  новый ключ в личном кабинете и замените значение `GIGACHAT_AUTH_KEY`.
- **«Port 3000 is in use»** — сайт уже запущен в другом терминале. Закройте его
  (Ctrl + C) или откройте адрес, который напишет терминал (например, `http://localhost:3001`).
