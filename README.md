# Otti — английский с ИИ-репетитором

Otti — веб-приложение для изучения английского: короткие уроки от A1, словарь с повторением,
работа над ошибками, ИИ-репетитор — выдра Отти — и **подготовка к IELTS**.

Страница проверки сайта: `/status`. Публикация в интернете — в файле **DEPLOY_RENDER.md**.
Чек-лист владельца сайта — в файле **LAUNCH.md**.

## Что нового в версии 2

1. **Надёжный чат с Отти.** Раньше при временном сбое у провайдера ИИ (ошибка 503, перегрузка 429,
   долгий ответ) сразу появлялось «Otti не смог ответить». Теперь сервер сам повторяет запрос до
   двух раз с паузой. Если сбой не прошёл, сообщение не теряется: у него есть кнопки
   «Повторить отправку» и «Изменить текст». Когда пропадает интернет, сообщение уходит само, как
   только связь вернётся. Одно и то же сообщение никогда не сохраняется дважды, и XP за него не
   начисляется повторно.
2. **Игровые анимации и звуки** в стиле Отти. Звуки можно выключить, анимации — уменьшить (Профиль →
   «Звуки и анимации»). Системная настройка «Уменьшить движение» тоже учитывается.
3. **Раздел «Экзамены»**: полноценная подготовка к IELTS (Academic и General Training) —
   диагностика, учебный план, Reading, Listening, Writing Task 1 и 2, Speaking Parts 1–3, примерный
   Band Score и прогресс. TOEFL, Cambridge и школьные экзамены пока показаны как «Скоро».
4. **Смена цели из чата.** Если написать Отти «Я хочу готовиться к IELTS» (по-русски или
   по-английски), он ответит по-русски и предложит перейти к подготовке. Цель меняется только
   после нажатия «Да».

## Первый запуск

1. Распакуйте архив и откройте папку проекта в VS Code: **File → Open Folder…** → папка `otti`.
2. Откройте терминал: **Terminal → New Terminal**.
3. Один раз установите библиотеки (1–3 минуты):

   ```
   npm install
   ```

4. Запустите сайт:

   ```
   npm run dev
   ```

5. Откройте в браузере адрес **http://localhost:3000**.
6. Чтобы остановить сайт, нажмите в терминале **Ctrl + C**.

## Как обновиться с версии этапа 13

Прогресс учеников хранится в папке `.data`, а ваши ключи — в файле `.env.local`. **Их нельзя удалять.**

1. Остановите сайт: в терминале **Ctrl + C**.
2. Сделайте резервную копию: скопируйте всю папку `otti` рядом, например в `otti-backup`.
3. Распакуйте архив версии 2 **в новую папку**, например `otti-v2`.
4. Скопируйте из старой папки в новую:
   - папку `.data` (если её не видно, в Проводнике включите **Вид → Показать → Скрытые элементы**);
   - файл `.env.local`.
5. Откройте новую папку в VS Code и выполните в терминале по очереди:

   ```
   npm install
   ```

   ```
   npm run dev
   ```

   Перед запуском `npm run dev` сам добавит в базу новые таблицы и колонки
   (в терминале появится строка `✓ Локальная база данных: таблицы в порядке`).
6. Откройте **http://localhost:3000** и войдите своим аккаунтом — XP, серия, словарь и уроки сохранятся.

> Если у вас в `.env.local` указан `AI_PROVIDER=openrouter` с сервисом, где закончились токены,
> временно поставьте `AI_PROVIDER=mock` — Отти будет отвечать заготовками, а все разделы
> (включая IELTS) можно проверить без расходов.

## Как проверить новые функции

**Чат с Отти**
1. «Репетитор» → любая тема → напишите сообщение. Пока Отти отвечает, кнопка отправки заблокирована
   и видно «Отти печатает…».
2. Выключите Wi-Fi и отправьте сообщение: появится «Нет интернета. Сообщение отправится само…».
   Включите Wi-Fi — сообщение уйдёт без повторного нажатия.
3. Напишите «Я хочу готовиться к IELTS» → Отти ответит по-русски и покажет кнопки
   «Да, готовиться к IELTS» / «Нет, продолжим разговор».

**Анимации и звуки**
1. Пройдите урок: карточки выезжают, при верном ответе — зелёная «волна» и радостный Отти,
   при ошибке — мягкое покачивание и растерянный Отти.
2. В конце урока — празднование, «набегающие» XP, вспышка огонька серии и достижения.
3. Кнопка с динамиком в шапке урока выключает звуки. В профиле — «Звуки» и «Уменьшить анимации».

**IELTS**
1. Меню «Экзамены» → «Начать подготовку к IELTS» → ответьте на шесть вопросов → появится план.
2. «Пройти диагностику» (25–30 минут) → примерный стартовый уровень.
3. Reading: выберите текст → «Учебный режим» или «Как на экзамене» → ответьте → «Сдать ответы» →
   разбор каждой ошибки → «Работа над ошибками».
4. Writing: напишите эссе → «Проверить с Отти» → оценки по четырём критериям и ошибки
   (исправленный вариант открывается кнопкой «Показать исправление»).
5. Speaking: ответьте голосом (Chrome, Edge, Safari) или текстом → разбор ответа.
6. «Подробный прогресс и весь план» — баллы по навыкам, история, повторяющиеся ошибки, время.

## Подготовка к IELTS

- Все тексты, записи и задания **оригинальные** — написаны для Otti в формате экзамена.
  Материалы настоящих экзаменов не используются.
- **Reading**: 6 текстов (3 Academic, 3 General Training); типы вопросов — Multiple Choice,
  True/False/Not Given, Yes/No/Not Given, Matching Headings, Sentence Completion, Summary Completion.
- **Listening**: 4 части экзамена. Звук создаёт синтезатор речи браузера — это **учебная
  демонстрация**, а не имитация экзаменационного аудио. Если в браузере нет английского голоса,
  показывается текст записи.
- **Writing**: Task 1 Academic (графики и таблица), Task 1 General Training (письма), Task 2 (эссе).
  Таймер, счётчик слов, автосохранение черновика, примеры структуры и полезные фразы.
- **Speaking**: Part 1 (вопросы о себе), Part 2 (карточка, минута на подготовку), Part 3 (обсуждение).
- **Оценка.** Reading и Listening проверяет сервер по ключам ответов; примерный балл считается
  по доле верных ответов. Writing и Speaking оценивает ИИ — везде написано: «Оценка создана ИИ,
  является приблизительной и не является официальным результатом IELTS». Балл всегда показывается
  диапазоном с уровнем уверенности; по слишком короткому ответу балл не выставляется.
- **Произношение** по текстовой расшифровке точно оценить нельзя — Отти даёт только осторожные
  подсказки, и только если ответ был голосом.
- **Лимиты.** Проверки Writing и Speaking тратят больше токенов, поэтому у них отдельные дневные
  лимиты (по умолчанию 3 и 5, переменные `IELTS_WRITING_CHECKS_PER_DAY`,
  `IELTS_SPEAKING_CHECKS_PER_DAY`). Один и тот же текст проверяется один раз: повторная проверка
  и обновление страницы показывают сохранённый результат и лимит не тратят.
- **Учебный план** составляется без ИИ: по дате экзамена, числу занятий в неделю и сложному
  навыку (ему — вдвое больше занятий). После диагностики план уточняется.
- Контент: `src/content/ielts/`; расчёты баллов и проверка — `src/lib/exams/ielts.ts`;
  план и готовность — `src/lib/exams/plan.ts`; проверка ИИ — `src/lib/exams/ai-feedback.ts`.

## Надёжность чата и сообщения об ошибках

- Каждый запрос к ИИ получает короткий код (например, `a1b2c3d4`). Если что-то пошло не так,
  ученик видит понятный текст и «Код ошибки». Этот же код стоит в журнале сервера рядом
  с технической причиной: в терминале (`npm run dev`) или в Logs на Render — ищите `req=a1b2c3d4`.
- Сервер повторяет запрос при тайм-ауте, 429 и ошибках 500–504 (до 2 раз, с растущей паузой).
  Ошибки ключа (401/403), оплаты (402) и неверного запроса (400) не повторяются — их нужно исправлять
  в настройках.
- Что означают сообщения:
  - **«Нет интернета…»** — пропала связь у ученика; сообщение уйдёт само.
  - **«Слишком много сообщений подряд…»** — минутный лимит; сообщение отправится само через счётчик.
  - **«На сегодня лимит сообщений исчерпан»** — дневной лимит ученика.
  - **«Сервер ИИ временно недоступен»** — провайдер ИИ не ответил даже после повторов (частая причина —
    перегрузка бесплатных или дешёвых моделей). Можно нажать «Повторить отправку» через минуту.
  - **«Сервис ИИ сейчас перегружен запросами»** — провайдер отвечает 429.
  - **«У ИИ-репетитора закончились запросы у провайдера»** — закончились токены или деньги у провайдера.
  - **«Отти временно недоступен: на сервере ошибка настроек ИИ»** — неверный ключ или модель.
  - **«Сессия закончилась»** — нужно войти снова; текст сообщения сохранится и уйдёт после входа.
- **Честно о бесплатных лимитах.** Если ИИ-провайдер часто отвечает 503 или 429, дело в его
  перегрузке или лимитах, а не в Otti. Технические решения уже встроены: повторы, минутный лимит на
  ученика, кэш проверок эссе. Ещё одно бесплатное решение — запасной провайдер
  (`AI_FALLBACK_PROVIDER`, например GigaChat с бесплатным пакетом для физлиц). Платные сервисы
  не подключены.
- Длинный разговор: ИИ получает последние 12 сообщений целиком и краткое содержание начала.

## ИИ-репетитор

- Все запросы к ИИ идут только с сервера (`src/lib/ai/index.ts`). Ключи API в браузер не попадают.
- Провайдеры: **GigaChat**, **OpenRouter** (или совместимый сервис через `OPENROUTER_BASE_URL`),
  **YandexGPT** (платный), **mock** — тестовый режим без ключей. Основной — `AI_PROVIDER`,
  запасной — `AI_FALLBACK_PROVIDER`.
- Выключить ИИ на всём сайте: `AI_ENABLED=false`. Уроки, словарь, ошибки и задания Reading/Listening
  продолжат работать.
- Проверить подключение: `/status` → «Проверить связь с Отти» (видно владельцу из `ADMIN_EMAILS`,
  на компьютере — всем).

## Анимации и звуки

- Анимации сделаны на CSS, без дополнительных библиотек: карточки, прогресс, верный и неверный ответ,
  реакции Отти, XP, празднование, серия, открытие урока, достижения, сообщения чата, заготовки
  страниц при загрузке. Длятся 0,2–0,9 секунды.
- Звуки создаются в браузере программно (Web Audio API) — никаких аудиофайлов и чужих звуков.
- Настройки «Звуки» и «Уменьшить анимации» хранятся в профиле и действуют на всех устройствах.

## Учебный курс, словарь, ошибки

- Уроки — в `src/content/course/`; прогресс — в базе. Сервер перепроверяет ответы перед начислением XP.
- Словарь: статусы «новое → учу → выучено», повторение через 1, 3, 7, 14 и 30 дней.
- Работа над ошибками: задания с ошибками из уроков и тренировка по ним.
- Серия дней растёт, когда за день набрана дневная цель; 11 достижений — в `src/lib/achievements.ts`.

## Безопасность

- Ключи API читаются только на сервере и не попадают в код для браузера (это проверено
  автоматически сборкой с «ключами-метками»).
- Каждое серверное действие проверяет вход и работу только со своими данными.
- Ответы Reading и Listening, уроков и тренировок проверяет сервер; XP нельзя «накрутить»:
  за задание IELTS — один раз в день, за сообщение Отти — один раз даже при повторах.
- Защитные заголовки (CSP, HSTS на хостинге) — в `next.config.ts`.
- Пользователь видит только короткий код ошибки — без ключей, адресов и технических подробностей.

## Известные ограничения

- Listening озвучивает синтезатор браузера — это учебная демонстрация, акценты и темп отличаются от
  экзамена. На некоторых устройствах английского голоса нет — тогда показывается текст записи.
- Голосовой ответ в Speaking работает в Chrome, Edge и Safari (не в Firefox). Произношение по
  расшифровке точно не оценивается.
- Оценки Writing и Speaking примерные и зависят от качества модели ИИ; в тестовом режиме (`mock`)
  это заготовки.
- Заданий IELTS: 6 текстов Reading, 4 части Listening, 10 заданий Writing, 12 тем Speaking.
  TOEFL, Cambridge и школьные экзамены — в планах.
- Нет восстановления пароля по e-mail (нужен почтовый сервис).
- Готов вводный раздел A1 (5 уроков); уровни A2–B2 — следующая большая работа.

## Частые проблемы

- **«npm не является внутренней или внешней командой»** — Node.js не установлен
  или компьютер не перезагружен после установки.
- **«выполнение сценариев отключено в этой системе»** — выполните в терминале
  `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`, затем введите `Y`.
- **После обновления пропал прогресс** — не скопирована папка `.data`. Остановите сайт,
  скопируйте `.data` из резервной копии в новую папку и снова запустите `npm run dev`.
- **«Сервер ИИ временно недоступен» с кодом ошибки** — найдите этот код в терминале: рядом будет
  причина (например, `OpenRouter: сбой на стороне провайдера (код 503)`).
- **`/status`: «ИИ-репетитор: Тестовый режим»** — не задан ключ ИИ или указан `AI_PROVIDER=mock`.
- **«Port 3000 is in use»** — сайт уже запущен в другом терминале. Закройте его (Ctrl + C)
  или откройте адрес, который напишет терминал (например, `http://localhost:3001`).
- **Нет звука в уроке** — проверьте значок динамика в шапке урока и «Звуки» в профиле;
  на iPhone звук не играет в беззвучном режиме.
