# Otti — чек-лист запуска

Этот файл — памятка владельцу сайта: что проверить перед тем, как показывать Otti другим людям,
как управлять сайтом после запуска и что доделать перед настоящим публичным запуском.

## 1. Настройки на Vercel

Проект → **Settings → Environment Variables**. После любых изменений — **Deployments → ⋯ → Redeploy**.

| Переменная | Нужна? | Что это |
|---|---|---|
| `DATABASE_URL`, `DATABASE_URL_UNPOOLED` | да | Добавляются сами, когда подключена база Neon (вкладка Storage) |
| `BETTER_AUTH_SECRET` | да | Секретный ключ для входа (этап 3) |
| `AI_PROVIDER` | да | `gigachat` |
| `GIGACHAT_AUTH_KEY` | да | Ключ авторизации GigaChat (этап 10) |
| `ADMIN_EMAILS` | да | Твой e-mail: только тебе на `/status` видны подробности и проверка ИИ |
| `AI_FALLBACK_PROVIDER`, `OPENROUTER_API_KEY` | желательно | Запасной ИИ, если GigaChat не ответит |
| `CONTACT_EMAIL` | желательно | Почта для вопросов о данных — показывается на `/privacy` |
| `AI_ENABLED` | нет | `false` — выключить ИИ на всём сайте |
| `AI_USER_DAILY_LIMIT` и другие лимиты | нет | Значения по умолчанию — в `.env.example` |

## 2. Проверка перед показом друзьям

- [ ] `/status` (войдя своим аккаунтом): все строки зелёные, «Проверить связь с Отти» отвечает через GigaChat.
- [ ] В режиме инкогнито: регистрация → знакомство → урок 1 → словарь → ошибки → чат с Отти → «Завершить».
- [ ] Отти исправляет ошибку карточкой «Твой ответ / Правильно / Почему».
- [ ] Профиль: смена пароля работает; тестовый аккаунт удаляется («Удалить аккаунт»).
- [ ] Телефон: сайт устанавливается как приложение, голосовой ввод в чате работает.
- [ ] Выход из аккаунта и повторный вход.

## 3. Управление после запуска

- **Выключить ИИ**, если что-то пошло не так: `AI_ENABLED=false` → Redeploy. Уроки, словарь и ошибки продолжат работать.
- **Расход ИИ**: `/status` — сколько запросов сегодня; остаток бесплатных токенов — в личном кабинете GigaChat (Studio).
- **Лимиты**: `AI_USER_DAILY_LIMIT` (на ученика в день), `AI_GLOBAL_DAILY_LIMIT` (на весь сайт в день).
- **Ошибки сервера**: Vercel → проект → **Logs**. Ищи строки с `[ai]`, `[tutor]`, `[lesson]`.
- **Резервные копии**: в Neon есть восстановление базы на прошлый момент — проверь, на сколько дней назад оно доступно в твоём тарифе.
- **Обновления кода**: как на всех этапах — `git add .`, `git commit -m "…"`, `git push`; Vercel опубликует сам.

## 4. Что сейчас не умеет Otti (честно)

- Нет восстановления пароля по e-mail и подтверждения почты — для этого нужен почтовый сервис.
- Готов только вводный раздел A1 (5 уроков); уровни A2–B2 — следующая большая работа.
- Не проверено, отвечает ли GigaChat серверам Vercel в Европе, — это покажет `/status` после публикации.
- Голосовой ввод зависит от браузера (нет в Firefox).

## 5. Перед настоящим публичным запуском и монетизацией

Это не юридическая консультация — перед коммерческим запуском стоит поговорить с юристом.

- **Персональные данные (152-ФЗ).** Нужны: официальная политика обработки данных (страница `/privacy` —
  понятное описание, но не юридический документ), согласие пользователя, уведомление Роскомнадзора
  об обработке данных. Закон также требует хранить данные граждан РФ на серверах в России — сейчас
  база Neon находится в Европе. Для коммерческого сервиса базу нужно перенести в российское облако
  (например, Yandex Cloud или Selectel).
- **Почта**: подтверждение e-mail и «Забыли пароль?» (сервис рассылки писем).
- **Защита регистрации**: капча (например, Yandex SmartCaptcha) от массовых фальшивых аккаунтов.
- **Свой домен**: подключить в Vercel и задать `BETTER_AUTH_URL`.
- **Оплата**: в базе уже есть поле тарифа (`plan`) — задел под подписку.
- **Контент**: уроки A1–B2 по той же схеме, что и вводный раздел (`src/content/course/`).
