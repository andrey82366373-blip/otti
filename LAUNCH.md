# Otti — чек-лист запуска

Этот файл — памятка владельцу сайта: что проверить перед тем, как показывать Otti другим людям,
как управлять сайтом после запуска и что доделать перед настоящим публичным запуском.

## 1. Настройки на Render

Как опубликовать сайт впервые — в файле **DEPLOY_RENDER.md**. Настройки: Render → сервис **otti** →
**Environment**. После изменений — **Save, rebuild, and deploy**.

| Переменная | Нужна? | Что это |
|---|---|---|
| `DATABASE_URL`, `DATABASE_URL_UNPOOLED` | да | Строки подключения из Neon (с пулом и без) |
| `BETTER_AUTH_SECRET` | да | Секретный ключ для входа — Render создаёт его сам по `render.yaml` |
| `ADMIN_EMAILS` | да | Твой e-mail: только тебе на `/status` видны подробности и проверка ИИ |
| `AI_PROVIDER` | да | `mock` (заготовки), `openrouter` или `gigachat` |
| `OPENROUTER_API_KEY`, `OPENROUTER_BASE_URL`, `OPENROUTER_MODEL` | для OpenRouter / crouter | Ключ, адрес и модель |
| `GIGACHAT_AUTH_KEY` | для GigaChat | Ключ авторизации GigaChat |
| `AI_FALLBACK_PROVIDER` + ключ второго провайдера | желательно | Запасной ИИ, если основной не ответит после повторов |
| `CONTACT_EMAIL` | желательно | Почта для вопросов о данных — показывается на `/privacy` |
| `AI_ENABLED` | нет | `false` — выключить ИИ на всём сайте |
| `IELTS_WRITING_CHECKS_PER_DAY`, `IELTS_SPEAKING_CHECKS_PER_DAY` | нет | Проверок эссе и устных ответов в день (по умолчанию 3 и 5) |
| `AI_USER_DAILY_LIMIT` и другие лимиты | нет | Значения по умолчанию — в `.env.example` |

## 2. Проверка перед показом друзьям

- [ ] `/status` (войдя своим аккаунтом): все строки зелёные, «Проверить связь с Отти» отвечает.
- [ ] В режиме инкогнито: регистрация → знакомство → урок 1 → словарь → ошибки → чат с Отти → «Завершить».
- [ ] Отти исправляет ошибку карточкой «Твой ответ / Правильно / Почему».
- [ ] Чат: «Я хочу готовиться к IELTS» → ответ по-русски и кнопки «Да / Нет».
- [ ] «Экзамены» → IELTS: настройка цели → план → один текст Reading → одно эссе Writing → «Проверить с Отти».
- [ ] Профиль: «Звуки» и «Уменьшить анимации» переключаются; смена пароля работает;
      тестовый аккаунт удаляется («Удалить аккаунт»).
- [ ] Телефон: сайт устанавливается как приложение, голосовой ввод в чате и Speaking работает.
- [ ] Выход из аккаунта и повторный вход.

## 3. Управление после запуска

- **Выключить ИИ**, если что-то пошло не так: `AI_ENABLED=false` → Save. Уроки, словарь, ошибки,
  Reading и Listening продолжат работать.
- **Расход ИИ**: `/status` — сколько запросов сегодня; остаток токенов — в личном кабинете провайдера.
- **Лимиты**: `AI_USER_DAILY_LIMIT` (на ученика в день), `AI_GLOBAL_DAILY_LIMIT` (на весь сайт в день),
  отдельные лимиты проверок IELTS.
- **Ошибки сервера**: Render → сервис → **Logs**. Ищи строки с `[ai]`, `[tutor]`, `[exams]`, а по коду
  ошибки из сообщения ученика — `req=код`.
- **Резервные копии**: в Neon есть восстановление базы на прошлый момент (Branches → Restore) —
  проверь, на сколько часов назад оно доступно в бесплатном тарифе.
- **Обновления кода**: `git add .`, `git commit -m "…"`, `git push` — Render опубликует сам.

## 4. Что сейчас не умеет Otti (честно)

- Нет восстановления пароля по e-mail и подтверждения почты — для этого нужен почтовый сервис.
- Готов только вводный раздел A1 (5 уроков); уровни A2–B2 — следующая большая работа.
- IELTS: оценки Writing и Speaking примерные (ИИ), Listening озвучивает синтезатор браузера —
  это учебная демонстрация. TOEFL и Cambridge — в планах.
- Не проверено, отвечает ли GigaChat серверам Render во Франкфурте, — это покажет `/status` после публикации.
- Бесплатный сайт на Render «засыпает» после 15 минут без посетителей; первый заход — около минуты.
- Голосовой ввод зависит от браузера (нет в Firefox).

## 5. Перед настоящим публичным запуском и монетизацией

Это не юридическая консультация — перед коммерческим запуском стоит поговорить с юристом.

- **Персональные данные (152-ФЗ).** Нужны: официальная политика обработки данных (страница `/privacy` —
  понятное описание, но не юридический документ), согласие пользователя, уведомление Роскомнадзора
  об обработке данных. Закон также требует хранить данные граждан РФ на серверах в России — сейчас
  база Neon находится в Европе. Для коммерческого сервиса базу нужно перенести в российское облако
  (например, Yandex Cloud или Selectel).
- **Почта**: подтверждение e-mail и «Забыли пароль?» (сервис рассылки писем).
- **Защита регистрации**: капча (например, Yandex SmartCaptcha) от массовых фальшивых аккаунтов.
- **Свой домен**: подключить в Render (Settings → Custom Domains) и задать `BETTER_AUTH_URL`.
- **Оплата**: в базе уже есть поле тарифа (`plan`) — задел под подписку.
- **Контент**: уроки A1–B2 по той же схеме, что и вводный раздел (`src/content/course/`).
